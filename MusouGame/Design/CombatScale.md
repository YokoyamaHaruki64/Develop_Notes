# 大群殲滅アクション — 戦闘規模とゲーム体験

- 対象：LEIR／3D無双アクション＋部屋攻略型ローグライト
- 状態：**方向性は確定**。体数・殲滅時間・性能数値は**仮目標／要検証**。
- 更新：2026-11-11
- 関連：[ゲーム概要](Overview.md)／[戦闘仕様](Combat.md)／[敵AI](Enemies.md)／[ステージ共通仕様](Stage_Common.md)

## 1. コンセプト【方針確定】

**数百体の敵を一度に薙ぎ払い、数千体を数分で殲滅する3D無双アクション。**

- プレイヤー（リア）1人が、多数の敵と直接戦う。大規模な味方軍勢同士の戦争は想定しない。
- 戦場全体の表示人数ではなく、**プレイヤーが直接相手にする敵の密度・規模**と**累計KillCount**を重視する。
- 通常の部屋攻略・平常時の戦闘で数千体を殲滅することを目標とし、特殊チャレンジ限定の体験にしない。
- HestiaEngineのECS性能を活用する一方、敵数の最大化よりも**操作感・爽快感・戦闘のメリハリ**を優先する。
- 技術的な最大Entity数の検証はゲーム本編とは分離し、独立した技術デモで行う。

## 2. 群れの規模・配置【構成方針確定／数値仮】

| 項目 | 仮目標 |
| --- | --- |
| 1群れの敵数 | **300〜500体** |
| フィールドに存在する群れ | **3〜4群れ** |
| 同時存在する敵数 | **約900〜2,000体** |
| 通常の部屋・戦闘での累計撃破数 | **数分で数千体**を目指す |
| 敵の最大数 | ゲーム性・実機性能を基に再設定（固定上限は未決定） |

- 群れはフィールド内の異なる地点に**独立して配置**する。
- プレイヤーが接近した群れと交戦し、殲滅後に次の群れへ移動することを基本とする。
- 吹き飛ばした敵の着地・衝突が**別の群れ全体の警戒／合流を連鎖的に引き起こす**仕組みは、現時点では採用しない。
- 遠くにいる群れが自動的に合流して巨大な一集団となり、群れごとの戦闘の区切りが失われることを避ける。
- **既存の敵AI設計との関係**：SpawnGroup所属は維持し、複数の敵が同時にプレイヤーを認識した場合にCombatGroupへ統合する既存仕様（[Enemies.md](Enemies.md)）は変更しない。群れ間距離・認識範囲・接敵タイミングで、基本的に別群れが同時認識しないように設計する。
- プレイヤー自身が別の群れへ近づいた場合の連戦・複数群れ同時交戦は否定しない。

## 3. 戦闘サイクル【方針確定】

**群れへ接近 → 数百体との交戦 → 短時間で殲滅 → 次の群れへ移動 → 再び殲滅**

### 戦闘

- 数百体の密集した敵集団へ突入し、通常コンボで大量の敵を一斉に処理する。
- 少数の強敵を長く削る遊びではなく、群れの体数と形状が**コンボごとに目に見えて減る**爽快感を重視する。
- 撃破数の増加だけでなく、吹き飛ばしによって群れに空間が生じることを視覚的に伝える。

### 移動

- 殲滅から次の群れまでの移動は、戦闘を途切れさせる欠点ではなく、**戦闘と非戦闘の緩急**として積極的に活用する。
- 景観を見せる、次に攻略する群れを選ぶ、巨大な群れに再突入する期待を作る時間とする。
- 群れ同士を常に合流させたり、途切れない連続戦闘を必須にしたりしない。
- 1群れの殲滅時間・群れ間移動時間は実機で調整する。秒数の確定は行わない。

## 4. コンボによる殲滅力【方針確定／体数仮】

基本は**弱攻撃で集敵・ダメージ蓄積 → 強攻撃でまとめて撃破**。

| 攻撃 | 役割 |
| --- | --- |
| 弱1 | 数十体規模を攻撃してHPを削り、前方へ集敵する |
| 弱2 | さらにHPを削り、斬り上げ・吹き飛びによって強3へつなぐ |
| 強3（弱→弱→強） | 広範囲の敵をまとめて吹き飛ばして撃破する |

- 最終的な強化状態では、**弱→弱→強の1コンボで合計約100体撃破**を目標にする。
- 初期状態で100体倒せることは必須としない。ローグライト強化により巻き込み範囲・威力・殲滅力が成長する設計を想定する。
- 剣の見た目上の長さだけに実際の命中範囲を限定せず、斬撃エフェクト・衝撃波等で広範囲への攻撃を表現できるようにする。
- 各段の具体的な命中数・HP・攻撃判定・強化倍率は未決定。**命中した人数**と**撃破した人数**は区別して検証する。
- モーションの内容とコンボ進行規則は既存の [Combat.md](Combat.md) と [AttackMotion_WeakWeakStrong.md](AttackMotion_WeakWeakStrong.md) を正本とし、本資料で上書きしない。

## 5. ステージ設計への影響【要検証】

- 数百体単位の群れを3〜4つ独立配置できる広さと、密集した敵を吹き飛ばす余地を確保する。
- 群れ間に移動区間を持たせ、戦闘と移動のメリハリを作る。
- 草原の直径70〜100m、遺跡の直径80mなど**既存の個別ステージ案はそのまま維持**し、今回の群れ規模を実配置してから不足があれば寸法見直しを検討する。**現段階で寸法を変更した確定仕様にはしない。**
- ステージの形状やアセット制作の詳細は [Stage_Common.md](Stage_Common.md) と各ステージ資料を参照する。

## 6. HestiaEngineと性能目標【方針確定／性能未実測】

### ゲーム本編

- 大規模な敵AI・Transform・当たり判定・被弾・吹き飛び・死亡処理・描画を含む実際のゲーム負荷で**60fps**を目標とする。
- 本編の同時存在数はゲームの面白さを基準に決める。**数千体**は有力な目標だが、具体的な上限は未確定。
- 数千体を継続的に倒す際の生成・破棄・演出負荷も対象とする。
- ECS単体のEntity管理性能と、AI・描画等を含むゲーム全体の性能は混同しない。

### 独立した技術デモ

| 項目 | ゲーム本編 | 技術デモ |
| --- | --- | --- |
| 目的 | 大群殲滅の爽快感と完成度 | エンジンの限界・性能特性の検証 |
| 敵・Entity数 | プレイ体験で決定 | 条件を明示して段階的に増やす |
| 評価 | 操作感・安定フレームレート・大量撃破 | Entity数・FPS・CPU/GPU時間等 |

- **10,000体／60fps**は現時点で実ゲーム負荷を計測済みの実績ではなく、挑戦可能性のある技術目標として扱う。
- ゲーム本編で10,000体を同時に出すことは必須条件としない。

## 7. 未決定・要検証項目

- 1群れの最適な体数、密度、群れ間距離、認識範囲。
- 各攻撃の実命中数・撃破数・敵HPと最終強化時の殲滅力。
- 1群れの殲滅所要時間と、次の群れまでの移動時間。
- 1部屋で数千体倒すための初期配置・補充方式・部屋クリア条件の関係。
- 既存の個別ステージ寸法で数百体×複数群れが成立するか。
- AI・アニメーション・当たり判定・衝突・死亡演出・描画を含めた実測FPS。
- エンジンの最大Entity数デモで採用する負荷条件と計測方法。

## 優先順位

1. **爽快感**：数百体の群れを通常コンボで薙ぎ払う。
2. **戦闘規模**：通常プレイで数千体の累計撃破数に到達する。
3. **メリハリ**：独立した群れを殲滅し、次の群れまで移動する。
4. **性能**：自作エンジンのECSを活かし、ゲーム全体を安定動作させる。

> 本資料はゲーム体験と規模の方針を定めるもの。敵AI・戦闘・ステージの既存詳細仕様や実装値を未検証の数値で上書きしない。
